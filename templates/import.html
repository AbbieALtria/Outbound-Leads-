How outcomes map

VOICEMAIL, NO ANSWER, ANSWERED, BUSY, Wrong Department/Numbercalled
NOT INTERESTEDnot interested
INTERESTED, SALEinterested
CALL BACKcallback
DO NOT CALLdnc — excluded from every future pull and export
AFTRS, DROPPED, inbound rowsignored

The file just needs a column with "phone" in its header and a status_name column (or the outcome in the last column). If a number appears several times, the last outcome wins — except DO NOT CALL, which always wins. Statuses you set by hand (interested, callback, not interested) are never downgraded by an import; only DO NOT CALL overrides them.
