Real-time intake API

Lead vendors can POST leads to you in real time. Point them at:

EndpointPOST /api/intake
HeaderX-Intake-Key: <your key>
Bodyapplication/json

Example body:

{
  "name": "Jane Doe",
  "phone": "813-555-0142",
  "email": "jane@example.com",
  "city": "Tampa", "state": "FL", "zip": "33601",
  "product_interest": "Solar",
  "consent": true,
  "consent_at": "2026-07-16T10:22:00Z",
  "source": "PX",
  "campaign_id": 3
}

Attach to a client by passing campaign_id (from the Campaigns page) or the client's vici_campaign_id. Or pass "campaign": "<offer-slug>" to only set the scoring offer. Omit all to leave the lead unassigned.
