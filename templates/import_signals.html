Import B2B intent signals (CSV)

Upload an export from a site-visitor tracker (Leadfeeder / Dealfront / Albacross) or an intent tool (Bombora / G2). Each row is matched to an existing lead by website domain first, then business name — no new lead is created (these sources have no phone). Unmatched rows are kept for review. Columns are auto-detected (company/account, domain/website, visits/score, last_seen date, and topic for intent).

Real-time signal webhook

Your intent vendor can POST signals in real time:

EndpointPOST /api/signal
HeaderX-Signal-Key: <your key>
Bodyapplication/json

Example body:

{
  "kind": "site_visitor",       // or "intent"
  "company_name": "Acme Roofing",
  "domain": "acmeroofing.com",
  "signal_strength": 7,          // visits or intent score
  "last_seen_date": "2026-07-20",
  "topic": "VoIP phone systems"  // intent only
}
